# Moussa Backups

Moussa Backups is the backup feature of Moussa Rent A Car, a private Windows desktop application used to run a car rental business.

It creates an encrypted backup of the business records on the owner's laptop and stores that file in the owner's own Google Drive.

The application is not offered to the public.
